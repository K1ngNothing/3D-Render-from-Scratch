# Курсовой проект "3D Render с нуля"
Выполнил студент БПМИ-215 Проскурин Александр Вадимович.

Данный проект имплементирует 3D рендер с нуля. Из примитивов отрисовки используется только библиотека SFML, которая используется для создания окна и отрисовки пикселей (но не для отрисовки фигур, например, треугольника). Все этапы рендеринга реализованы вручную и описаны в отчете `3D_Render_from_Scratch_report.pdf`.

# Course work "3D Render from Scratch"
This project implements 3D renderer from scratch. The only rendering primitive used is SFML library, which was used for easy window creation and pixel drawing (but it wasn't used for drawing figures, e.g. triangles). All steps of rendering pipeline were implemented by hand and were described in report `3D_Render_from_Scratch_report.pdf` (in russian).
